## Текущая база

Светлая тема, выросшая из `client_reference` (v1.6). Палитра живёт в
`:root` в `style.css`, стили слоями через `@layer` (base / legacy /
client / overrides).

**Цвета:**

```
--bg        #F4F1EA   тёплый кремовый фон
--surface   #ffffff   карточки
--text      #16181D   основной текст
--text-soft #71757E   вторичный текст
--border    #E4DFD4
--sidebar   #1c1917   тёмный сайдбар (подтверждён референсом)
--accent    #d0201b   кирпично-красный — ВРЕМЕННО, см. открытые вопросы
--green     #1F8A5B
--yellow    #F2C200
--red       #C23B2E
--cyan      #008FBE
```

**Шрифты:** Manrope (текст) + Unbounded (цифры/акценты).

**Радиус карточек:** 16px. Тёмная шапка таблиц `#171a22`.

## Решения по анимациям

> Направление: лёгкие микро-анимации в духе свежих iOS — быстрые
> (150–200мс), ненавязчивые. Это рабочий инструмент, не витрина.
> Без блюра, без параллакса, без тяжёлых эффектов.

- [ ] Чипы-фильтров: мягкая смена подсветки активного
- [ ] Модалки: плавное появление (опционально)

## Claude Design — рабочий процесс

Дизайн-система собрана из реального кода проекта (`index.html`,
`style.css`, скриншоты готовых экранов). Порядок работы:

1. Рисуем экран в Claude Design (шаблон **UI mockups**), гоняем варианты
2. Решение фиксируем здесь словами — что берём, что нет
3. Claude Code реализует на существующих классах и `@layer`

**Не переносить код из Design напрямую** — он не знает про `store.js`,
`@layer`, кросс-файловые `typeof`-вызовы и правило «никаких
prompt/confirm».

## Открытые вопросы по дизайну

1. **Акцентный цвет**: сейчас `#d0201b` (кирпично-красный). На референсе
   заказчика был голубой `#008FBE`. Какой правильный? Меняется одной
   строкой в `:root`.

   Возможна анимация.
3. Шрифт окончательно не утверждён разработчиком.
