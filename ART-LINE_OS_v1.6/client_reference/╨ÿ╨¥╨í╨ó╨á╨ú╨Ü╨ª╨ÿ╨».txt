ART-LINE OS v1.6 — мобильная версия и PWA

Как открыть локально:
1. Распакуйте ZIP.
2. Откройте index.html в браузере.
3. Для обычного просмотра на компьютере локального открытия достаточно.

Как установить на телефон как приложение:
1. Разместите содержимое папки на HTTPS-домене или тестовом HTTPS-хостинге.
2. Важно: на сервер нужно загрузить именно содержимое папки, а не сам ZIP.
3. Откройте ссылку на телефоне.
4. iPhone: Safari → Поделиться → На экран «Домой».
5. Android: Chrome → меню → Установить приложение / Добавить на главный экран.

Что добавлено в v1.5:
- Мобильный рабочий стол сотрудника.
- Мобильный пульс руководителя.
- Нижнее меню: Главная, Клиенты, Заказы, Задачи, Ещё.
- Быстрые действия после звонка.
- Быстрый поиск по клиентам, заказам, счетам, задачам, вопросам и документам.
- Мобильные карточки вместо широких таблиц.
- Кнопки позвонить / написать / добавить комментарий.
- Центр мобильных уведомлений.
- PWA-структура: manifest, service worker, иконки, тема, offline.html.
- Экран запуска и офлайн-заглушка.

Ограничения прототипа:
- Настоящая синхронизация между сотрудниками появится только после серверной части.
- Настоящие push-уведомления, авторизация, файловое хранилище и база данных — следующий серверный этап.
- Локальное открытие через file:// может не активировать service worker; для PWA нужен HTTPS или localhost.
